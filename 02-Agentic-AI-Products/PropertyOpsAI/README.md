# PropertyOps AI

An AI-assisted property maintenance application that helps tenants
report issues and property managers coordinate their resolution.

## Vision

Move maintenance issues from initial report to verified completion,
with appropriate human oversight.

## Planned first workflow

1. Tenant reports an issue using text and photos.
2. AI gathers missing details and assesses urgency.
3. The application retrieves relevant property information.
4. AI recommends a suitable vendor and next action.
5. An authorized property manager approves the action.
6. The application creates and tracks a work order.
7. The property manager verifies completion.

## Learning goals

- Multimodal AI
- Multi-agent coordination
- APIs and agent tools
- Human approvals and authorization
- AI evaluation and monitoring
- Product strategy and success metrics
